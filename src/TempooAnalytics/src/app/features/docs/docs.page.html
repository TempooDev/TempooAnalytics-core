Getting Started

Tempoo Analytics is a lightweight, privacy-focused analytics tool. To start tracking your website, include our script in your HTML. 

<script src="{{ scriptUrl }}" data-site="YOUR_SITE_KEY" data-key="YOUR_WRITE_KEY"{{ apiAttr }}></script>

Configuration Attributes

  • data-site: (Required) Your site's unique Key (slug).
  • data-key: (Required) Your authorized Write Key.
  • data-debug: Set to "true" to see console logs.
  • data-honor-dnt: Respect "Do Not Track" (default: true).

Automatic Tracking

By default, the script automatically tracks Pageviews. It handles Single Page Applications (SPAs) by listening to route changes, so no manual configuration is needed for basic traffic analysis.

Custom Events (Goals)

You can track specific user actions like button clicks, form submissions, or purchases using two methods.

1. Declarative Method (No Code)

Add the data-tempoo-goal attribute to any HTML element.

<button data-tempoo-goal="signup_clicked">Sign Up Now</button>

2. Programmatic Method (JavaScript)

Trigger events manually within your application logic using the global window.tempoo object. 

window.tempoo.track("purchase_completed", {{ '{' }} 
  amount: 49.99, 
  currency: "USD" 
{{ '}' }});

S Streamlit Integration guide

Streamlit renders components (including custom HTML) inside iframes. Using a standard injection "traps" the script, preventing global tracking. This guide shows how to inject the script into the parent window's <head> for global availability.

1. The Injection Script

Copy this function into your code. It uses a JavaScript "bridge" to jump from the iframe to the parent document's head. 

import streamlit.components.v1 as components

def inject_tempoo(site_id, write_key):
    """
    Injects the Tempoo script directly into the <head> of the parent document
    to ensure global availability and persistence.
    """
    tempoo_script = f"""
    <script>
        // Check if it already exists to avoid duplicates on Streamlit re-runs
        if (!window.parent.document.getElementById('tempoo-analytics')) {{ '{' }}
            const script = window.parent.document.createElement('script');
            script.id = 'tempoo-analytics';
            script.src = "{{ scriptUrl }}";{{ apiScriptLine }}
            script.setAttribute('data-site', '{{ '{' }}site_id{{ '}' }}');
            script.setAttribute('data-key', '{{ '{' }}write_key{{ '}' }}');
            script.defer = true;
            window.parent.document.head.appendChild(script);
        {{ '}' }}
    </script>
    """
    # The component is created with 0 height/width to be invisible
    components.html(tempoo_script, height=0, width=0)

# Call at the start of your app
inject_tempoo("YOUR_SITE_ID", "YOUR_WRITE_KEY")

window.parent

Accesses the main Streamlit window from within the component iframe.

appendChild

Dynamically creates the script element and moves it to the parent head.

Globality

The tempoo object becomes available session-wide for automatic SPA tracking.

3. Tracking Events from Python

Trigger custom events (like after an AI completion or a transaction) using this pattern: 

def track_event(event_name, params):
    js_code = f"""
    <script>
        if (window.parent.tempoo) {{ '{' }}
            window.parent.tempoo.track("{{ '{' }}event_name{{ '}' }}", {{ '{' }}params{{ '}' }});
        {{ '}' }}
    </script>
    """
    components.html(js_code, height=0, width=0)

if st.button("Simulate Purchase"):
    track_event("purchase_completed", {{ '{' }}"amount": 50, "currency": "EUR"{{ '}' }})

4. Verification

  1. Right-click your app -> Inspect.
  2. In the Elements tab, look for the <head> section.
  3. You should see <script id="tempoo-analytics" ...> directly under the main head.
B Blazor Integration guide

1. Global Installation

Add the script tag to your root file to make it available throughout the application.

  • Blazor WebAssembly: In wwwroot/index.html.
  • Blazor Server / Static SSR: In App.razor or _Host.cshtml (inside <head>). 
<script src="{{ scriptUrl }}" data-site="YOUR_SITE_KEY" data-key="YOUR_WRITE_KEY"{{ apiAttr }}></script>

2. Declarative Tracking (No Code)

Blazor handles custom attributes seamlessly. Add data-tempoo-goal to your components: 

<button data-tempoo-goal="signup_clicked" class="btn btn-primary">
    Sign Up
</button>

<button data-tempoo-goal="purchase" 
        data-tempoo-goal-product="laptop" 
        data-tempoo-goal-price="1200" 
        class="btn btn-success">
    Buy Now
</button>

3. Programmatic Tracking (JS Interop)

Use IJSRuntime to trigger events from C# code.

// Create a helper service

public class TempooService
{{ '{' }}
    private readonly IJSRuntime _js;
    public TempooService(IJSRuntime js) => _js = js;

    public async ValueTask TrackEvent(string eventName, object metadata = null)
    {{ '{' }}
        await _js.InvokeVoidAsync("tempoo.track", eventName, metadata);
    {{ '}' }}
{{ '}' }}

// Use it in your component

@inject TempooService Tempoo

<button @onclick="HandleLogin">Login</button>

@code {{ '{' }}
    async Task HandleLogin()
    {{ '{' }}
        // ... login logic ...
        await Tempoo.TrackEvent("login_success", new {{ '{' }} method = "auth0" {{ '}' }});
    {{ '}' }}
{{ '}' }}

4. The SPA Challenge (Navigation)

If the script doesn't automatically detect route changes, use NavigationManager to trigger pageviews manually: 

@inject NavigationManager NavManager
@inject IJSRuntime JS

@code {{ '{' }}
    protected override void OnInitialized()
    {{ '{' }}
        NavManager.LocationChanged += (s, e) => {{ '{' }}
            JS.InvokeVoidAsync("tempoo.track", "pageview"); 
        {{ '}' }};
    {{ '}' }}
{{ '}' }}

Pro Tip: To avoid "window.tempoo is undefined" errors, ensure you call programmatic functions within OnAfterRenderAsync(bool firstRender) when firstRender is true.

Conversion Funnels

Funnels allow you to visualize the user journey and identify where people drop off. Every event you track (Pageviews and Custom Events) can be used as a step in a Funnel.

Pro Tip: Create a funnel with steps like "Home Page" → "Registration Click" → "Signup Success" to analyze your conversion rate accurately.

Privacy & Ethics

  • 100% GDPR Compliant: We do not store any personal identifiable information (PII).
  • No persistent cookies are used for tracking.
  • IP addresses are anonymized and never stored in full.
  • Smart Analytics: We calculate essential metrics from raw events, including:
    • Device type and operating system.
    • Bounce rates and session duration.
    • Geographic location (country/region level).
  • We respect Do Not Track (DNT) browser settings by default.
